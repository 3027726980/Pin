# 文件预览抽屉高度优化设计

## 目标

消除文件预览抽屉底部因内容区固定为 650px 而产生的大块空白，让策略、原文和预览结果三列充分利用抽屉正文的可用高度。

## 设计

- 预览抽屉正文占满标题栏以下的剩余高度，并隐藏正文自身的滚动条。
- 预览布局在桌面端占满正文高度，三列保持等高。
- 策略列、原文列和结果列分别在自身内部滚动；切换结果标签不会改变抽屉整体高度。
- 移除 `650px` 固定高度和最小高度，改用 `height: 100%`、`min-height: 0` 与弹性布局传递可用高度。
- 屏幕宽度小于 1000px 时继续使用单列布局，恢复正文整体滚动和内容自然高度，避免移动端出现嵌套的狭窄滚动区。

## 影响范围

仅修改 `KnowledgeDetailView.vue` 的文件预览抽屉结构属性和样式，不改变预览、清洗、切片、保存或重新处理的数据流。

## 验证

- 增加回归测试，确保桌面端预览抽屉使用可用高度且不再包含 `650px` 固定上限。
- 运行知识库详情页相关测试和前端生产构建。
- 在桌面尺寸浏览器中打开文件预览，确认三列延伸至抽屉底部附近并各自可滚动；再检查窄屏单列回退。
