# 本地模型下载指南

本脚本用于一键下载本地模型（Embedding / Rerank），下载到 `config.yaml` 中
`local_models.cache_dir` 指定的目录，供 **local 厂商**配置使用（离线部署友好）。

---

## 一、环境准备

需要 Python 3.10+，并安装以下任一依赖：

```bash
# 方式一：ModelScope（魔搭，国内速度快，推荐）
pip install modelscope

# 方式二：HuggingFace（官方源）
pip install huggingface-hub
```

---

## 二、下载模型

在项目根目录执行：

```bash
# 下载 Rerank 模型（多语言精排）
python backend/script/download_models.py BAAI/bge-reranker-v2-m3

# 下载 Embedding 模型（中文向量化）
python backend/script/download_models.py bge-small-zh-v1.5

# 一键下载全部预置本地模型
python backend/script/download_models.py --all

# 查看预置模型列表
python backend/script/download_models.py --list
```

### 常用选项

| 参数 | 说明 |
|------|------|
| `--source` | 下载源：`modelscope` / `huggingface` / `auto`（默认 auto：优先魔搭，失败自动回退） |
| `--name` | 自定义本地目录名（默认 = 模型 ID） |
| `--all` | 下载全部预置模型 |

### 下载位置

自动读取 `config.yaml`：

```yaml
local_models:
  cache_dir: backend/local_models   # ← 下载到这里（可自行修改路径）
```

默认目录结构：

```
backend/local_models/
├── bge-small-zh-v1.5/            ← Embedding 模型（单级目录）
└── BAAI/bge-reranker-v2-m3/      ← Rerank 模型（两级目录）
```

---

## 三、配置使用

下载完成后，进入「模型配置」页面：

1. **添加模型** → 厂商选 `local`
2. **模型类型**：Embedding 选「Embedding（向量化）」；Rerank 选「Rerank（重排序）」
3. **模型名**：填写下载的模型名（如 `bge-small-zh-v1.5` / `BAAI/bge-reranker-v2-m3`）
4. 保存 → 点「测试连接」验证 ✅

### 使用场景

| 模型 | 用途 |
|------|------|
| `bge-small-zh-v1.5` | 知识库向量化（本地，零 API 成本） |
| `BAAI/bge-reranker-v2-m3` | Agent Rerank 精排（本地） |

---

## 四、常见问题

| 问题 | 解决方法 |
|------|---------|
| 提示未安装 modelscope / huggingface_hub | 按上文安装对应依赖 |
| 魔搭下载失败 | 加 `--source huggingface` 换源 |
| 下载中断/很慢 | 重新执行脚本，自动断点续传 |
| 提示"目录已存在，跳过" | 如需重下，先删除对应目录再执行 |
| 模型配置页测试报"本地模型不存在" | 检查模型名与目录名是否一致（含 `BAAI/` 前缀路径） |

---

## 五、离线部署提示

- 本地模型全部在 `local_models.cache_dir` 目录下，**打包部署时整个目录复制即可**，无需联网
- 模型加载使用 `local_files_only=True`，**不会联网自动下载**（保证离线环境可用）
